Overview of Oracle Order Management

Oracle Order Management enables you to capture orders from multiple channels, price orders, check product availability, schedule fulfillment, plan shipments, ship deliveries, and track shipments.

Oracle Order Management consists of:

  • Oracle Order Management

  • Oracle Shipping Execution

  • Basic Pricing
